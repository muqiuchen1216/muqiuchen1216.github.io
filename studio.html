连上以后，你在手机上直接就能改图和改文字，不用再开电脑、不用开服务器。 改完约半分钟，网站自动变成新的。

只需要做一次。钥匙（令牌）只存在这台设备的浏览器里，不会上传到任何地方； 别人没有这把钥匙，所以只能看，不能改。

还没有令牌？按这里生成一个

点下面的按钮会打开 GitHub 的生成页面（已帮你填好名字、有效期设为永不过期）， 你只需要做两件事：选仓库、把 Contents 设成 Read and write。

打开 GitHub 生成令牌 ↗
看图照做：详细三步
  1. Repository access 选 Only select repositories， 下拉里只勾 muqiuchen1216.github.io。
  2. 展开 Repository permissions，找到 Contents， 右边改成 Read and write。（Metadata 会自动变成只读，不用管）
  3. 滑到最下面点绿色 Generate token， 把出现的那一长串（github_pat_ 开头）复制下来， 粘到下面的框里。

那一串只显示这一次，关掉页面就再也看不到了。 复制后直接粘到下面，不要截图外传。

令牌设成了永不过期，所以它会一直有效 —— 好处是不用每年重弄；代价是万一泄露就一直有效。 如果手机丢了或者怀疑泄露，去 GitHub 设置里把它删掉即可，立即失效。

在这里更新摄影师资料、上传与管理作品。保存后首页会立刻变成最新的样子，不需要刷新页面。

资料与作品保存在这台电脑上（data/ 与 media/），不会上传到互联网。同一局域网里的手机、平板打开同一个网址，看到的就是同一份内容，改动会实时同步过去。
